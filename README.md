# NJ Drive 新泽西驾考练习

手机与电脑浏览器均可使用的中英双语刷题 PWA，版本 1.1.0。

## 使用

在线体验：[NJ Drive 新泽西驾考练习](https://nj-drive-study-20261103.oaken-note-6556.chatgpt.site)。在 Android Chrome 菜单选择“安装应用”或“添加到主屏幕”；在 iPhone Safari 选择“分享 → 添加到主屏幕”。安装能力取决于浏览器及站点访问环境。

本地运行：安装 Node.js 18+ 后，在此目录执行 `npm start`（或 `node serve.mjs`），打开 `http://127.0.0.1:4173`。Windows 也可运行 `启动应用.cmd`；启动前请安装 Node.js 18 或更新版本，并确保 node 位于 PATH 中。关闭本地服务后，已成功缓存的浏览器仍可离线练习。

也可将 dist/ 中的文件托管到 HTTPS 静态网站，须让全部资源位于同一个目录。直接双击 index.html 不能启用 PWA，原文 JSON 的读取也可能被浏览器限制。

## 功能

- 顺序全刷、随机 20 题、分类练习、按进度与关键词筛选。
- 50 题模拟，40 题通过；可选 30/45/60 分钟训练计时或不限时。训练时间并非官方考试时限。
- 默认学习模拟：每题作答后立即解析，答错自动定位到解析，显示所选项、正确项、规则和官方依据，首次答案锁定并计分。考试模拟仍可改答案，交卷后统一解析；已有考试可切换学习模拟。漏答计错，倒计时暂离后继续。
- 错误自动加入错题本；连续两次有效答对归档，再错重新加入。
- 收藏、题目中英切换、原文对照、每题依据及修订说明。
- 本机记录自动保存，支持 JSON 导出导入。不同设备之间通过备份手动转移，不含云端自动同步。
- 首次联网后完整缓存题库、原文与配图；设置页显示缓存状态。

## 题库与核对

从上传 Word 整理出 520 道选择题并逐题检查：488 道保留或修订，32 道因缺图、条件不足、无法确定唯一答案或依据不足退出判分库。共有 196 道原题修订了答案、条件、选项或翻译。结合 52 道按公开 MVC 资料编写的双语练习，正式判分库共 540 道。

原资料 670 个文本块（包括简答、不完整题及重复内容）和可读取配图保留在 original.json 与 assets/。原文保留错误答案作对照，不能把原稿答案当作现行规则。判分使用 bank.js 中的修订版本。

来源以 MVC 实际下载的 2026 英文手册、MVC 公开样题、官方专题说明及 FHWA MUTCD 为依据；查阅日期为 2026-11-03。手册共 243 PDF 页，题目引用的是印刷页，一般比 PDF 页码少 2。正式考试不是公开完整题库，本应用不声称含所有正式原题。

完整逐题审计记录见 dist/audit.json，应用内“题库来源”也列出修订及退出说明。法规可能更新，应结合 MVC 最新官方资料。

## 数据与维护

记录保存在浏览器 localStorage 的 nj-drive-v1。私密模式、清理站点数据或卸载浏览器可能移除记录，建议定期导出。备份导入替换已提交记录，不恢复正在进行的练习。

源码无第三方前端依赖或远程字体。core.js 提供抽题、判分、错题及备份校验逻辑；app.js 提供界面；sw.js 提供离线缓存；serve.mjs 是本地静态服务。运行 `npm test`（或 `node --test core.test.cjs`）检查题库约束、抽题、40 题及格边界、错题生命周期与备份校验。

若更新文件，应重新生成 sw.js 中的缓存版本和文件清单，避免旧资源继续留在离线缓存中。此仓库不包含原网站的托管身份配置，可将 dist/ 独立部署到 HTTPS 静态托管。
